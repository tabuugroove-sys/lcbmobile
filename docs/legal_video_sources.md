# Legal Celebrity Video Source Map

Use this as the sourcing order for long 16:9 editorial videos. A source is usable
only when the concrete asset has an explicit reuse license, press permission, or
paid editorial license. Search results and embeds are not enough.

## Free / Open Whitelist

1. Wikimedia Commons
   - Search: `site:commons.wikimedia.org "ARTIST" "webm"`
   - Search: `site:commons.wikimedia.org "ARTIST" "video"`
   - Search: `site:commons.wikimedia.org "ARTIST" "File:"`
   - Accept: `CC BY`, `CC BY-SA`, `CC0`, public domain.
   - Reject: screenshots, music-video captures, files with unclear source.

2. Wikimedia upload URLs
   - Use only when linked from a Commons file page with license metadata.
   - Store the Commons page URL and license in credits.

3. UN / ONU media
   - `media.un.org`
   - `un.org`
   - `news.un.org`
   - Good for public appearances, speeches, charity events.

4. World Economic Forum
   - `weforum.org`
   - `youtube.com/@wef` only if the page/license allows reuse.
   - Good for Shakira-style public forum footage.

5. Government / public broadcaster media with explicit license
   - Examples: `TV BrasilGov`, official public agency pages.
   - Verify `CC BY`, public domain, or reuse statement.

6. Internet Archive
   - Search: `site:archive.org "ARTIST" "movies"`
   - Accept only when `licenseurl` is present and compatible.
   - Reject random TV/music-video reuploads without license.

7. Vimeo Creative Commons
   - Search: `site:vimeo.com "ARTIST" "Creative Commons"`
   - Verify the actual Vimeo license on the asset page.

8. YouTube Creative Commons
   - Verify with metadata, not title text.
   - Accept only: `Creative Commons Attribution license (reuse allowed)`.
   - Reject: `license=None`, "no copyright" in title, fan reuploads without permission.

## Official Press / Permission Sources

9. Artist official press kit
   - Search: `ARTIST press kit`
   - Search: `ARTIST media kit`
   - Search: `ARTIST EPK`
   - Search: `ARTIST b-roll`
   - Need explicit press/editorial reuse terms.

10. Label / management press rooms
    - Examples: Sony Music, Warner, Universal, Roc Nation, artist management.
    - Need downloadable b-roll or written permission.

11. Festival press centers
    - Rock in Rio media center / press area.
    - Coachella, Lollapalooza, Tomorrowland, Ultra, Primavera.
    - Need event press terms and asset license.

12. Awards press centers
    - GRAMMYs media center.
    - BRIT Awards press area.
    - Billboard Music Awards press assets.
    - MTV VMAs / EMAs press assets.
    - Need media login or written permission.

13. Venue / promoter media rooms
    - Live Nation, AEG, ticketing/promoter press pages.
    - Usually permission-based.

14. Direct permission from creator
    - Fan footage is usable only with written permission from the uploader.
    - Mute original audio when concert music is audible.

## Paid Editorial Archives

15. Getty Images video/editorial
    - Search: `Getty ARTIST red carpet video`.
    - Use only after buying the correct YouTube/editorial license.

16. AP Archive
    - Search: `AP Archive ARTIST red carpet`.
    - Use only with license.

17. Reuters video
    - Search: `Reuters ARTIST red carpet video`.
    - Use only with license.

18. Shutterstock Editorial
    - Search: `Shutterstock Editorial ARTIST`.
    - Use only with license id.

19. Alamy
    - Editorial videos/photos, license required.

20. Pond5
    - Check editorial/commercial scope carefully.

21. Storyful / Newsflare
    - Useful for social/fan footage licensing.

22. WireImage / FilmMagic / Mega / Backgrid
    - Mostly celebrity arrival/red-carpet assets, license required.

## Hard Blacklist For Pipeline

- RuTracker and torrents.
- TV broadcast rips.
- YouTube `license=None`.
- Yandex previews when they resolve to unlicensed YouTube.
- TikTok / Instagram / X downloads without permission.
- Fan reuploads without written permission.
- Official music videos without explicit reuse permission.
